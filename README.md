# Data Club Meetings

This repository contains the materials used in [Columbia Data Club](https://library.columbia.edu/services/research-data-services/data-club.html) meetings. Mostly it holds datasets and example Jupyter/Colab notebooks.

It is a Python project managed by `uv`, so using it benefits from installing that:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Or you can use an [alternative installation method](https://docs.astral.sh/uv/getting-started/installation/#__tabbed_1_1).

With `uv` installed, then run:

```sh
uv sync
```

To launch Jupyter Lab in order to access the Jupyter notebook:

```sh
uv run jupyter lab
```
